# 문제 1: 배열 회전 (Array Rotation)

## 난이도
🟢 기본 (Basic)

## 문제 설명
정수 배열 `arr`와 양의 정수 `k`가 주어졌을 때, 배열을 오른쪽으로 `k`칸만큼 회전시킨 결과를 반환하세요.

예를 들어, `[1, 2, 3, 4, 5]`를 오른쪽으로 2칸 회전하면 `[4, 5, 1, 2, 3]`이 됩니다.

## 입력 형식
- `int[] arr`: 회전시킬 정수 배열 (길이: 1 ~ 1000)
- `int k`: 회전할 칸 수 (양수, 0 포함 가능)

## 출력 형식
- 오른쪽으로 `k`칸 회전한 새로운 배열

## 예제

### 예제 1
**입력:**
```
arr = [1, 2, 3, 4, 5]
k = 2
```
**출력:**
```
[4, 5, 1, 2, 3]
```

### 예제 2
**입력:**
```
arr = [1, 2, 3]
k = 5
```
**출력:**
```
[2, 3, 1]
```
*설명: 5칸 회전은 3칸 회전과 동일 (5 % 3 = 2)*

### 예제 3
**입력:**
```
arr = [1]
k = 10
```
**출력:**
```
[1]
```

## 제약조건
- 1 <= arr.length <= 1000
- -1000 <= arr[i] <= 1000
- 0 <= k <= 10^9

## 테스트 케이스
1. 일반적인 경우: `[1,2,3,4,5]`, k=2 → `[4,5,1,2,3]`
2. k가 배열 길이보다 큰 경우: `[1,2,3]`, k=5 → `[2,3,1]`
3. k=0인 경우: `[1,2,3]`, k=0 → `[1,2,3]`
4. 단일 원소: `[1]`, k=10 → `[1]`
5. k가 배열 길이의 배수: `[1,2,3,4]`, k=8 → `[1,2,3,4]`

## 힌트
1. k가 배열 길이보다 클 수 있으므로 `k % length`를 사용하세요.
2. 추가 배열을 사용하는 방법(O(n) 공간)과 제자리에서 하는 방법(O(1) 공간)을 모두 시도해보세요.
3. 제자리 회전 팁: 전체 반전 → 앞부분 반전 → 뒷부분 반전

## 시간 복잡도 목표
- O(n) 시간 복잡도
- O(1) 추가 공간 (선택적 도전)
