# 문제 7: 0 이동시키기 (Move Zeroes with Constraints)

## 난이도
🔴 고급 (Advanced)

## 문제 설명
정수 배열 `arr`가 주어졌을 때, 모든 `0`을 배열의 **끝으로 이동**시키세요. 

**제약조건:**
1. **0 이 아닌 원소들의 상대적 순서**를 유지해야 합니다.
2. 추가 배열을 사용하지 않고 **제자리(in-place)**에서 수정해야 합니다.
3. **최소한의 연산**으로 수행해야 합니다.

## 입력 형식
- `int[] arr`: 정수 배열 (길이: 1 ~ 10000)

## 출력 형식
- 없음 (배열을 제자리에서 수정)

## 예제

### 예제 1
**입력:**
```
arr = [0, 1, 0, 3, 12]
```
**출력:**
```
[1, 3, 12, 0, 0]
```

### 예제 2
**입력:**
```
arr = [0, 0, 1]
```
**출력:**
```
[1, 0, 0]
```

### 예제 3
**입력:**
```
arr = [1, 2, 3]
```
**출력:**
```
[1, 2, 3]
```
*설명: 0 이 없으므로 변화 없음*

### 예제 4
**입력:**
```
arr = [0, 0, 0]
```
**출력:**
```
[0, 0, 0]
```

### 예제 5
**입력:**
```
arr = [5, 0, 0, 3, 0, 2, 0, 1]
```
**출력:**
```
[5, 3, 2, 1, 0, 0, 0, 0]
```

## 제약조건
- 1 <= arr.length <= 10000
- -2³¹ <= arr[i] <= 2³¹ - 1
- 0 <= arr[i] <= 2³¹ - 1 (일부 테스트케이스)

## 테스트 케이스
1. 일반적인 경우: `[0,1,0,3,12]` → `[1,3,12,0,0]`
2. 앞쪽에 0 집중: `[0,0,1]` → `[1,0,0]`
3. 0 없음: `[1,2,3]` → `[1,2,3]`
4. 모두 0: `[0,0,0]` → `[0,0,0]`
5. 복잡한 경우: `[5,0,0,3,0,2,0,1]` → `[5,3,2,1,0,0,0,0]`

## 힌트
1. **투 포인터 기법**을 사용하세요:
   - `nonZeroPos`: 0 이 아닌 원소를 배치할 다음 위치
   - 배열을 한 번 순회하며 0 이 아닌 원소들을 앞으로 배치
   
2. 두 단계 접근:
   - 1 단계: 0 이 아닌 모든 원소를 앞으로 이동 (상대적 순서 유지)
   - 2 단계: 나머지 위치를 0 으로 채움
   
3. 또는 단일 패스로도 가능합니다:
   - 0 이 아닌 원소를 발견하면 `nonZeroPos` 로 스왑
   - 단, 이 방법은 불필요한 스왑이 발생할 수 있음

## 시간 복잡도 목표
- O(n) 시간 복잡도
- O(1) 추가 공간
- **최소한의 스왑/연산**
