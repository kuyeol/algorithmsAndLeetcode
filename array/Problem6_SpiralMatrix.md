# 문제 6: 스파이럴 행렬 생성 (Spiral Matrix Generation)

## 난이도
🔴 고급 (Advanced)

## 문제 설명
양의 정수 `n`이 주어졌을 때, `1`부터 `n²`까지의 숫자를 **나선형 (spiral)**으로 채운 `n x n` 행렬을 생성하세요.

나선형은 다음과 같은 순서로 채워집니다:
1. 오른쪽 방향으로 시작
2. 시계방향으로 회전 (오른쪽 → 아래 → 왼쪽 → 위 → 오른쪽...)
3. 이미 채워진 셀이나 경계에 도달하면 방향을 전환

## 입력 형식
- `int n`: 행렬의 크기 (1 <= n <= 20)

## 출력 형식
- `int[][]`: 나선형으로 채워진 n x n 행렬

## 예제

### 예제 1
**입력:**
```
n = 3
```
**출력:**
```
[
  [1, 2, 3],
  [8, 9, 4],
  [7, 6, 5]
]
```

### 예제 2
**입력:**
```
n = 1
```
**출력:**
```
[[1]]
```

### 예제 3
**입력:**
```
n = 4
```
**출력:**
```
[
  [1,  2,  3,  4],
  [12, 13, 14, 5],
  [11, 16, 15, 6],
  [10, 9,  8,  7]
]
```

## 제약조건
- 1 <= n <= 20
- n 은 정수

## 테스트 케이스
1. n=3: 3x3 나선형 행렬
2. n=1: 1x1 행렬 ([[1]])
3. n=4: 4x4 나선형 행렬
4. n=2: 2x2 나선형 행렬 ([[1,2],[4,3]])
5. n=5: 5x5 나선형 행렬

## 힌트
1. **방향 배열**을 사용하세요:
   - `directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}}` (오른쪽, 아래, 왼쪽, 위)
   
2. 현재 위치와 방향을 추적하며:
   - 다음 위치가 유효하고 아직 채워지지 않았다면 이동
   - 그렇지 않으면 방향을 전환 (시계방향)
   
3. 또는 **경계를 축소**하는 방식:
   - top, bottom, left, right 경계 유지
   - 각 방향별로 경계를 따라 채우고 경계 축소

## 시간 복잡도 목표
- O(n²) 시간 복잡도 (모든 셀을 한 번씩 방문)
- O(n²) 공간 복잡도 (결과 행렬)
