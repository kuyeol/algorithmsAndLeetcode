# 배열 조작 알고리즘 퀴즈 (Array Manipulation Quiz)

## 개요
이 퀴즈는 배열 조작과 관련된 알고리즘 문제를 다룹니다. 기본부터 고급 수준까지 다양한 난이도의 문제를 포함하고 있습니다.

## 난이도별 문제 구성

### 🟢 기본 (Basic)
- **문제 1**: 배열 회전 (Array Rotation)
- **문제 2**: 중복 제거 (Remove Duplicates)

### 🟡 중급 (Intermediate)
- **문제 3**: 최대 부분합 (Maximum Subarray Sum)
- **문제 4**: 배열 분할 (Partition Array)

### 🔴 고급 (Advanced)
- **문제 5**: 다음 순열 (Next Permutation)
- **문제 6**: 스파이럴 행렬 생성 (Spiral Matrix Generation)
- **문제 7**: 0 이동시키기 (Move Zeroes with Constraints)

=

## 학습 목표
1. 배열의 기본 조작 기술 습득
2. 투 포인터, 슬라이딩 윈도우 등 고급 기법 이해
3. 시간/공간 복잡도 분석 능력 향상
4. 실제 코딩 테스트 대비


모든 문제는 내장된 테스트 케이스를 포함하고 실행 시 자동 검증
