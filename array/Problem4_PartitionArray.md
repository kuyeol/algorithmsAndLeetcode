# 문제 4: 배열 분할 (Partition Array)

## 난이도
🟡 중급 (Intermediate)

## 문제 설명
정수 배열 `arr`와 정수 `k`가 주어졌을 때, 배열을 다음과 같이 분할하세요:
- `k`보다 작은 원소들은 왼쪽으로
- `k`보다 크거나 같은 원소들은 오른쪽으로

**중요:**
- 추가 배열을 사용하지 않고 **제자리(in-place)**에서 수정해야 합니다.
- 각 그룹 내에서의 상대적 순서는 유지되지 않아도 됩니다.
- 함수는 분할된 배열에서 `k`보다 작은 원소들의 개수를 반환합니다.

## 입력 형식
- `int[] arr`: 정수 배열 (길이: 0 ~ 10000)
- `int k`: 분할 기준이 되는 정수

## 출력 형식
- `k`보다 작은 원소들의 개수 (int)
- 배열 자체는 제자리에서 수정됨 (왼쪽: k 미만, 오른쪽: k 이상)

## 예제

### 예제 1
**입력:**
```
arr = [3, 2, 2, 1]
k = 2
```
**출력:**
```
1
arr 분할 후: [1, 2, 2, 3] (또는 [1, ...])
```
*설명: 2 보다 작은 원소는 1 뿐입니다.*

### 예제 2
**입력:**
```
arr = [1, 2, 3, 4, 5]
k = 3
```
**출력:**
```
2
arr 분할 후: [1, 2, ...] (앞 2 개는 3 미만)
```

### 예제 3
**입력:**
```
arr = [5, 5, 5, 5]
k = 5
```
**출력:**
```
0
arr 분할 후: [5, 5, 5, 5] (변화 없음)
```

### 예제 4
**입력:**
```
arr = [1, 1, 1, 1]
k = 2
```
**출력:**
```
4
arr 분할 후: [1, 1, 1, 1] (모두 2 미만)
```

## 제약조건
- 0 <= arr.length <= 10000
- -10000 <= arr[i], k <= 10000

## 테스트 케이스
1. 일반적인 경우: `[3,2,2,1]`, k=2 → 1
2. 중간 분할: `[1,2,3,4,5]`, k=3 → 2
3. 모두 k 이상: `[5,5,5,5]`, k=5 → 0
4. 모두 k 미만: `[1,1,1,1]`, k=2 → 4
5. 빈 배열: `[]`, k=5 → 0

## 힌트
1. **투 포인터 기법**을 사용하세요:
   - 한 포인터는 배열의 시작에서
   - 다른 포인터는 배열의 끝에서
2. 또는 단일 패스로도 해결 가능합니다:
   - `smaller` 포인터: k 미만 원소들의 다음 위치
   - 배열을 순회하며 k 미만 원소를 발견하면 `smaller` 위치로 스왑
3. 퀵소트의 분할(partition) 연산과 유사합니다.

## 시간 복잡도 목표
- O(n) 시간 복잡도
- O(1) 추가 공간
