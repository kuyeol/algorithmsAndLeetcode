# 문제 3: 최대 부분합 (Maximum Subarray Sum)

## 난이도
🟡 중급 (Intermediate)

## 문제 설명
정수 배열 `arr`가 주어졌을 때, **연속된** 부분 배열의 합 중 가장 큰 값을 찾으세요.

부분 배열은 최소한 하나의 원소를 포함해야 합니다.

## 입력 형식
- `int[] arr`: 정수 배열 (길이: 1 ~ 100000)

## 출력 형식
- 최대 부분합 (int)

## 예제

### 예제 1
**입력:**
```
arr = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
```
**출력:**
```
6
```
*설명: [4, -1, 2, 1] 의 합이 6 으로 가장 큽니다.*

### 예제 2
**입력:**
```
arr = [1]
```
**출력:**
```
1
```

### 예제 3
**입력:**
```
arr = [5, 4, -1, 7, 8]
```
**출력:**
```
23
```
*설명: 전체 배열 [5, 4, -1, 7, 8] 의 합이 23 입니다.*

### 예제 4
**입력:**
```
arr = [-1, -2, -3]
```
**출력:**
```
-1
```
*설명: 모든 원소가 음수일 경우, 가장 큰 단일 원소를 선택합니다.*

## 제약조건
- 1 <= arr.length <= 100000
- -10000 <= arr[i] <= 10000

## 테스트 케이스
1. mixed 양수/음수: `[-2,1,-3,4,-1,2,1,-5,4]` → 6
2. 단일 원소: `[1]` → 1
3. 모두 양수: `[5,4,-1,7,8]` → 23
4. 모두 음수: `[-1,-2,-3]` → -1
5. 교차하는 경우: `[1, -1, 1, -1, 1]` → 1

## 힌트
1. **카다네 알고리즘(Kadane's Algorithm)**을 사용하세요.
2. 각 위치에서 "지금까지의 최대 합"과 "전체 최대 합"을 추적합니다.
3. 현재 위치에서의 최대 합은:
   - `max(현재원소, 현재원소 + 이전까지최대합)`
4. O(n) 시간에 해결할 수 있습니다.

## 시간 복잡도 목표
- O(n) 시간 복잡도
- O(1) 추가 공간
