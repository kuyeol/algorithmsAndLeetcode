# 문제 5: 다음 순열 (Next Permutation)

## 난이도
🔴 고급 (Advanced)

## 문제 설명
숫자로 이루어진 배열 `arr`가 주어졌을 때, **사전순으로 다음에 오는 순열**을 구하세요.

만약 현재 순열이 가장 큰 순열이라면, **가장 작은 순열**(오름차순 정렬)로 만드세요.

**중요:**
- 추가 배열을 사용하지 않고 **제자리(in-place)**에서 수정해야 합니다.
- O(1) 추가 메모리만 사용해야 합니다.

## 사전순 비교란?
두 순열을 왼쪽부터 비교했을 때, 처음으로 다른 위치에서 더 작은 숫자를 가진 순열이 더 작습니다.

예: `[1, 2, 3]` < `[1, 3, 2]` < `[2, 1, 3]` < `[3, 2, 1]`

## 입력 형식
- `int[] arr`: 숫자로 이루어진 배열 (길이: 1 ~ 1000)

## 출력 형식
- 없음 (배열을 제자리에서 수정)

## 예제

### 예제 1
**입력:**
```
arr = [1, 2, 3]
```
**출력:**
```
[1, 3, 2]
```

### 예제 2
**입력:**
```
arr = [3, 2, 1]
```
**출력:**
```
[1, 2, 3]
```
*설명: 가장 큰 순열이므로 가장 작은 순열로*

### 예제 3
**입력:**
```
arr = [1, 1, 5]
```
**출력:**
```
[1, 5, 1]
```

### 예제 4
**입력:**
```
arr = [1, 3, 2]
```
**출력:**
```
[2, 1, 3]
```

### 예제 5
**입력:**
```
arr = [2, 3, 1]
```
**출력:**
```
[3, 1, 2]
```

## 제약조건
- 1 <= arr.length <= 1000
- 0 <= arr[i] <= 100
- 모든 원소는 정수

## 테스트 케이스
1. 일반적인 경우: `[1,2,3]` → `[1,3,2]`
2. 최대 순열: `[3,2,1]` → `[1,2,3]`
3. 중복 포함: `[1,1,5]` → `[1,5,1]`
4. 중간 경우: `[1,3,2]` → `[2,1,3]`
5. 또 다른 경우: `[2,3,1]` → `[3,1,2]`

## 힌트
다음 순열을 찾는 알고리즘:

1. **오른쪽에서 왼쪽으로**_scan하며_, `arr[i] < arr[i+1]`인 첫 번째 위치 `i`를 찾습니다.
   - 없으면 현재 순열이 가장 큰 것이므로 전체를 뒤집습니다.
   
2. 그런 다음, **오른쪽에서 왼쪽으로**_scan하며_, `arr[i]`보다 큰 첫 번째 원소 `arr[j]`를 찾습니다.

3. `arr[i]`와 `arr[j]`를 스왑합니다.

4. 위치 `i+1`부터 끝까지의 부분을 **뒤집습니다**(reverse).

## 시간 복잡도 목표
- O(n) 시간 복잡도
- O(1) 추가 공간
