# 문제 2: 중복 제거 (Remove Duplicates)

## 난이도
🟢 기본 (Basic)

## 문제 설명
정렬된 정수 배열 `arr`에서 중복된 원소를 제거하고, 중복이 제거된 배열의 새로운 길이를 반환하세요.

**중요:** 
- 추가 배열을 사용하지 않고 **제자리(in-place)**에서 수정해야 합니다.
- O(1) 추가 메모리만 사용해야 합니다.
- 함수가 새로운 길이를 반환하면, 길이만큼의 첫 번째 원소들이 고유한 값이어야 합니다.

## 입력 형식
- `int[] arr`: 정렬된 정수 배열 (길이: 0 ~ 10000)

## 출력 형식
- 중복 제거 후 배열의 새로운 길이 (int)
- 배열 자체는 제자리에서 수정됨

## 예제

### 예제 1
**입력:**
```
arr = [1, 1, 2]
```
**출력:**
```
2
arr의 처음 2개 원소: [1, 2, ...]
```

### 예제 2
**입력:**
```
arr = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
```
**출력:**
```
5
arr의 처음 5개 원소: [0, 1, 2, 3, 4, ...]
```

### 예제 3
**입력:**
```
arr = []
```
**출력:**
```
0
```

## 제약조건
- 0 <= arr.length <= 10000
- -100 <= arr[i] <= 100
- arr은 오름차순으로 정렬되어 있음

## 테스트 케이스
1. 일반적인 중복: `[1,1,2]` → 길이 2, `[1,2,...]`
2. 여러 중복: `[0,0,1,1,1,2,2,3,3,4]` → 길이 5
3. 빈 배열: `[]` → 길이 0
4. 모든 원소가 동일: `[1,1,1,1]` → 길이 1, `[1,...]`
5. 중복 없음: `[1,2,3,4,5]` → 길이 5

## 힌트
1. 배열이 정렬되어 있으므로 중복된 원소는 항상 인접해 있습니다.
2. 투 포인터 기법을 사용하세요:
   - 한 포인터는 현재 고유 원소의 위치를跟踪
   - 다른 포인터는 배열을 탐색
3. 새로운 원소를 발견하면 다음 위치에 저장하세요.

## 시간 복잡도 목표
- O(n) 시간 복잡도
- O(1) 추가 공간
