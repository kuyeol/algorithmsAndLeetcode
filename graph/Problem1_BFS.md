# 문제 1: BFS 그래프 탐색

## 문제 설명

주어진 정점에서 시작하여 그래프를 너비 우선 탐색(BFS)으로 순회하는 알고리즘을 구현하세요. 탐색은 도달 가능한 모든 정점을 레벨 순서로 방문해야 합니다.

## 요구 사항

1. 인접 리스트 표현을 사용하는 `Graph` 클래스 작성
2. BFS 순서로 정점 목록을 반환하는 `bfs(int startVertex)` 메서드 구현
3. 모든 컴포넌트를 방문하여 비연결 그래프 처리
4. 시간 복잡도: O(V + E)

## 입력 형식
- 정점 수 (V)
- 간선 목록 (무방향)
- BFS 시작 정점

## 출력 형식
- BFS 탐색 순서의 정점 목록

## 예시

**입력:**
```
정점: 6
간선: [(0,1), (0,2), (1,3), (1,4), (2,5)]
시작: 0
```

**출력:**
```
[0, 1, 2, 3, 4, 5]
```

## 제약 조건
- 0 ≤ V ≤ 1000
- 정점 번호: 0 ~ V-1
- 그래프가 비연결일 수 있음

## 테스트 케이스

### 테스트 케이스 1
정점 0에서 시작하는 단순 연결 그래프

### 테스트 케이스 2
비연결 그래프 — 모든 컴포넌트 방문

### 테스트 케이스 3
정점이 1개인 그래프

### 테스트 케이스 4
완전 그래프

## 힌트
1. 큐(Queue) 자료구조 활용
2. 불리언 배열 또는 Set으로 방문 여부 추적
3. 비연결 컴포넌트 처리 잊지 말 것
