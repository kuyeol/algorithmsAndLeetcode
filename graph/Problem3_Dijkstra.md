# 문제 3: 다익스트라 최단 경로 알고리즘

## 문제 설명

음수가 아닌 간선 가중치를 가진 가중 그래프에서 출발 정점으로부터 모든 다른 정점까지의 최단 경로를 찾는 다익스트라 알고리즘을 구현하세요.

## 요구 사항

1. 인접 리스트를 사용한 `WeightedGraph` 클래스 작성
2. 모든 정점까지의 최단 거리를 반환하는 `dijkstra(int source)` 메서드 구현
3. 실제 경로를 반환하는 `getShortestPath(int source, int destination)` 메서드 구현
4. 효율적인 구현을 위해 우선순위 큐(PriorityQueue) 사용
5. 시간 복잡도: O((V + E) log V)

## 입력 형식
- 정점 수 (V)
- 가중치가 있는 간선 목록 (u, v, 가중치)
- 출발 정점
- 선택 사항: 도착 정점

## 출력 형식
- 출발 정점에서 모든 정점까지의 최단 거리 배열
- 최단 경로를 구성하는 정점 목록 (도착 정점이 지정된 경우)

## 예시

### 예시 1: 단순 그래프
**입력:**
```
정점: 5
간선: [(0,1,4), (0,2,1), (2,1,2), (1,3,1), (2,3,5), (3,4,3)]
출발: 0
```

**출력:**
```
거리: [0, 3, 1, 4, 7]
4번 정점까지의 경로: [0, 2, 1, 3, 4]
```

### 예시 2: 비연결 그래프
**입력:**
```
정점: 4
간선: [(0,1,5), (2,3,2)]
출발: 0
```

**출력:**
```
거리: [0, 5, ∞, ∞]
(정점 2와 3은 도달 불가)
```

## 제약 조건
- 0 ≤ V ≤ 1000
- 0 ≤ 가중치 ≤ 10000
- 모든 간선 가중치는 음수가 아님
- 정점 번호: 0 ~ V-1

## 테스트 케이스

### 테스트 케이스 1
유일한 최단 경로를 가진 단순 연결 그래프

### 테스트 케이스 2
정점 간 여러 경로가 존재하는 그래프

### 테스트 케이스 3
도달 불가능한 정점이 있는 비연결 그래프

### 테스트 케이스 4
정점이 1개인 그래프

### 테스트 케이스 5
완전 그래프

### 테스트 케이스 6
선형 그래프 (체인)

## 힌트
1. 우선순위 큐에 (정점, 거리) 쌍 저장
2. 거리 배열을 무한대로 초기화
3. 경로 복원을 위해 이전 정점(predecessor) 추적
4. 더 짧은 경로를 발견한 경우에만 해당 정점 처리
5. 주의: 다익스트라는 음수 간선 가중치에서 동작하지 않음!

## 심화 과제
1. 음수 간선 가중치 처리를 위한 벨만-포드로 변환
2. 단일 최단 경로 대신 k번째 최단 경로 탐색
3. 휴리스틱 기반 탐색을 위한 A* 알고리즘 구현
4. 동적 그래프 업데이트 지원 추가
