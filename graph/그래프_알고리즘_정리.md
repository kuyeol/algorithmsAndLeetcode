

### 🧭 1. 그래프 탐색 및 경로 (Graph Traversal & Path)
그래프를 순회하거나 특정 조건을 만족하는 경로를 찾는 기본 및 심화 알고리즘입니다.

| 알고리즘 (링크) | 핵심 키워드 | 상세 설명 |
| :--- | :---: | :--- |
| 🔗 **[Bellman-Ford Algorithm<br>(Edge List)](https://github.com/kuyeol/Algorithms/blob/master/src/main/java/com/williamfiset/algorithms/graphtheory/BellmanFordEdgeList.java)** | `최단 경로`<br>`음수 가중치` | 간선 리스트(Edge List)를 기반으로 구현되었으며, **음수 가중치가 존재하는 그래프**에서도 단일 출발지 최단 경로를 안전하게 찾는 알고리즘입니다. |
| 🔗 **[Eulerian Path<br>(Directed, Adjacency List)](https://github.com/kuyeol/Algorithms/blob/master/src/main/java/com/williamfiset/algorithms/graphtheory/EulerianPathDirectedEdgesAdjacencyList.java)** | `오일러 경로`<br>`한 붓 그리기` | 방향 그래프 내에서 **모든 간선을 정확히 한 번씩만 통과**하는 경로(오일러 경로)를 찾는 알고리즘입니다. |
| 🔗 **[Depth First Search<br>(Recursive)](https://github.com/kuyeol/Algorithms/blob/master/src/main/java/com/williamfiset/algorithms/graphtheory/DepthFirstSearchAdjacencyListRecursive.java)** | `DFS`<br>`재귀 호출` | 인접 리스트를 활용하여 그래프를 깊이 우선으로 탐색하는 가장 기본적인 **재귀 방식의 DFS** 구현체입니다. |

### 🧩 2. 연결 요소 및 단절선 (Connected Components & Bridges)
그래프의 구조적 특징(연결 상태, 취약점 등)을 파악하는 알고리즘입니다.

| 알고리즘 (링크) | 핵심 키워드 | 상세 설명 |
| :--- | :---: | :--- |
| 🔗 **[Connected Components<br>(Union-Find)](https://github.com/kuyeol/Algorithms/blob/master/src/main/java/com/williamfiset/algorithms/graphtheory/ConnectedComponentsUnionFind.java)** | `연결 요소`<br>`Union-Find` | 서로소 집합(Disjoint Set) 자료구조를 사용하여 그래프 내의 **독립적인 연결 요소들을 효율적으로 그룹화**하고 판별합니다. |
| 🔗 **[Connected Components<br>(DFS)](https://github.com/kuyeol/Algorithms/blob/master/src/main/java/com/williamfiset/algorithms/graphtheory/ConnectedComponentsDfs.java)** | `연결 요소`<br>`DFS 탐색` | 깊이 우선 탐색(DFS)을 순차적으로 수행하여 그래프가 **몇 개의 연결된 덩어리로 나뉘어 있는지** 찾습니다. |
| 🔗 **[Bridges<br>(Adjacency List)](https://github.com/kuyeol/Algorithms/blob/master/src/main/java/com/williamfiset/algorithms/graphtheory/BridgesAdjacencyList.java)** | `단절선`<br>`취약점 분석` | 해당 간선을 제거했을 때 **그래프가 두 개 이상으로 쪼개지는 핵심 간선**인 '단절선(Bridge)'을 찾는 알고리즘입니다. |

### 🌊 3. 네트워크 플로우 (Network Flow)
네트워크 상에서 유량(Flow)을 최대로 흘려보내는 방법과 그 응용을 다룹니다.

| 알고리즘 (링크) | 핵심 키워드 | 상세 설명 |
| :--- | :---: | :--- |
| 🔗 **[Ford-Fulkerson<br>(DFS, Adjacency Matrix)](https://github.com/kuyeol/Algorithms/blob/master/src/main/java/com/williamfiset/algorithms/graphtheory/networkflow/FordFulkersonDFSAdjacencyMatrix.java)** | `최대 유량`<br>`포드-풀커슨` | 인접 행렬과 DFS를 이용하여 증가 경로(Augmenting Path)를 찾고, 네트워크의 **최대 유량(Max Flow)을 계산**하는 기본 알고리즘입니다. |
| 🔗 **[Ford-Fulkerson<br>Example](https://github.com/kuyeol/Algorithms/blob/master/src/main/java/com/williamfiset/algorithms/graphtheory/networkflow/examples/FordFulkersonExample.java)** | `사용법`<br>`기본 예제` | 포드-풀커슨 알고리즘 클래스를 인스턴스화하고 **실제 그래프 데이터를 주입하여 결과를 도출**하는 방법을 보여주는 튜토리얼 코드입니다. |
| 🔗 **[Mice and Owls<br>Example](https://github.com/kuyeol/Algorithms/blob/master/src/main/java/com/williamfiset/algorithms/graphtheory/networkflow/examples/MiceAndOwls.java)** | `응용 문제`<br>`이분 매칭` | 쥐들이 올빼미를 피해 제한된 용량의 구멍으로 숨는 상황을 **네트워크 플로우 문제로 모델링하여 해결**하는 흥미로운 응용 예제입니다. |
