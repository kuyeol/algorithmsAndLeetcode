**정답:** C) 방향 비순환 그래프 (DAG)

### 문제 5: 벨만-포드 복잡도
벨만-포드 알고리즘의 시간 복잡도는?
- A) O(V + E)
- B) O(V log V)
- C) O(V * E)
- D) O(E log V)

**정답:** C) O(V * E)

## 개념 문제

### 문제 1: BFS vs DFS
BFS와 DFS의 핵심 차이점을 설명하고, 각각 어떤 상황에서 사용하는지 서술하시오.

**핵심 포인트:**
- BFS는 큐 사용, DFS는 스택(또는 재귀) 사용
- BFS는 비가중 그래프에서 최단 경로 탐색 가능, DFS는 불가능
- BFS는 레벨 순서로 탐색, DFS는 깊이 우선 탐색
- BFS: 최단 경로, 레벨 순서 탐색에 적합
- DFS: 사이클 감지, 위상 정렬, 모든 경로 탐색에 적합

### 문제 2: 크루스칼 vs 프림 알고리즘
최소 신장 트리(MST)를 구하는 크루스칼 알고리즘과 프림 알고리즘을 비교하시오.

**핵심 포인트:**
- 크루스칼: 모든 간선 정렬, Union-Find 사용, 희소 그래프에 유리
- 프림: 정점에서 확장, 우선순위 큐 사용, 밀집 그래프에 유리
- 적절한 자료구조 사용 시 두 알고리즘 모두 O(E log V)
- 크루스칼은 간선 리스트 기반, 프림은 인접 리스트/행렬 기반

### 문제 3: 인접 행렬 vs 인접 리스트
인접 행렬과 인접 리스트는 각각 어떤 상황에서 사용해야 하는가?

**핵심 포인트:**
- 인접 행렬: 간선 조회 O(1), 공간 O(V²), 밀집 그래프에 적합
- 인접 리스트: 간선 조회 O(차수), 공간 O(V + E), 희소 그래프에 적합
- 간선 존재 여부를 자주 확인할 때는 행렬이 유리
- 이웃 정점 순회 시에는 리스트가 유리

1. **Union-Find 구현**: 경로 압축과 랭크 기반 합집합을 적용한 Union-Find 구현

3. **플로이드-워샬**: 모든 쌍 최단 경로 알고리즘 구현
4. **강한 연결 요소**: 코사라주 또는 타잔 알고리즘 구현
5. **외판원 문제**: 비트마스크 동적 프로그래밍으로 TSP 풀기
