# 문제 2: 그래프 사이클 감지

## 문제 설명

그래프에 사이클이 존재하는지 감지하는 알고리즘을 구현하세요. 방향 그래프와 무방향 그래프 모두 처리해야 합니다.

## 요구 사항

1. 방향/무방향 그래프를 모두 지원하는 `Graph` 클래스 작성
2. DFS를 사용한 무방향 그래프용 `hasCycle()` 메서드 구현
3. 재귀 스택을 활용한 DFS 기반 방향 그래프용 `hasCycleDirected()` 메서드 구현
4. 시간 복잡도: O(V + E)

## 입력 형식
- 정점 수 (V)
- 간선 목록
- 그래프 유형 (방향 또는 무방향)

## 출력 형식
- 그래프에 사이클 존재 여부 (불리언)

## 예시

### 예시 1: 사이클이 있는 무방향 그래프
**입력:**
```
정점: 4
간선: [(0,1), (1,2), (2,3), (3,0)]
유형: 무방향
```
**출력:** `true`

### 예시 2: 사이클이 없는 무방향 그래프
**입력:**
```
정점: 4
간선: [(0,1), (1,2), (2,3)]
유형: 무방향
```
**출력:** `false`

### 예시 3: 사이클이 있는 방향 그래프
**입력:**
```
정점: 4
간선: [(0,1), (1,2), (2,3), (3,1)]
유형: 방향
```
**출력:** `true`

### 예시 4: 사이클이 없는 방향 그래프 (DAG)
**입력:**
```
정점: 4
간선: [(0,1), (0,2), (1,3), (2,3)]
유형: 방향
```
**출력:** `false`

## 제약 조건
- 0 ≤ V ≤ 1000
- 정점 번호: 0 ~ V-1
- 자기 루프 및 동일한 정점 쌍 간의 중복 간선 없음

## 테스트 케이스

### 테스트 케이스 1
단순 사이클이 있는 무방향 그래프

### 테스트 케이스 2
트리 형태의 무방향 그래프 (사이클 없음)

### 테스트 케이스 3
후향 간선(back edge)으로 사이클이 생기는 방향 그래프

### 테스트 케이스 4
방향 비순환 그래프 (DAG)

### 테스트 케이스 5
간선이 없는 단일 정점

### 테스트 케이스 6
한 컴포넌트에만 사이클이 있는 비연결 그래프

## 힌트

### 무방향 그래프:
1. DFS 탐색 사용
2. 부모 정점 추적으로 역방향 이동 방지
3. 부모가 아닌 이미 방문한 정점을 만나면 사이클 존재

### 방향 그래프:
1. DFS에서 세 가지 상태 사용: 미방문 / 방문 중(재귀 스택 내) / 방문 완료
2. "방문 중" 상태의 정점을 만나면 사이클 존재
3. 위상 정렬 감지와 유사한 방식

## 심화 과제
1. 실제 사이클 경로 반환
2. 가중 그래프에서 사이클 감지
3. 그래프 내 사이클 수 세기
